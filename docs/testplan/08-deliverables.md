## 8. Test Deliverables

- Test Plan (this document)
- Test cases (manual and automated) – `docs/testplan/test-cases/`
- Test scripts – Pytest suites, Postman collection, Playwright scripts, Locust file
- Test data – seed scripts for the small and the large data set
- Test execution logs – GitHub Actions run history and manual execution records
- Defect reports – GitHub Issues with severity labels
- Performance test report – Locust charts and p95 tables
- Security test report – OWASP ZAP and TLS scan results
- Test Summary Report – final results, metrics (§14) and release recommendation
